# Вдвоём 2.0: принятый проект

Принят владельцем 14.11.2026. Кликабельный прототип: `docs/v2/prototype.html` (открыть в браузере).
Этот файл описывает, что строим. Экран, который расходится с ним, не готов.

## Вкладки и экраны

Нижняя панель: Главная, Идеи, Помощник (кружок по центру), Дела, Планы. Панель видна на всех экранах.

| Экран | Что на нём |
|---|---|
| Главная | Не листается. Одна строка «Ждёт тебя» (остальные листом), карточка свайпа на всё свободное место с вкладками «Наши / Афиша», внизу две плитки: ближайшая встреча и сводка дел. Помощника на главной нет |
| Главная без пары | Зачем звать, текст приглашения, «Пригласить», «＋ Идея», «＋ Дело» |
| Приглашение | Кто зовёт, что делают вдвоём, «Принять». Отдельные состояния: ссылка устарела, уже использована, человек уже в паре |
| Идеи | «Наши» (сетка, фильтр «Все / Мои / партнёра»), «Афиша» (списком и по дням, фильтр по виду), «Совпало» |
| Карточка идеи | Одна для всех идей: поля с пометкой, кто заполнил; отметка «Хочу / Не моё»; отметка партнёра; «Идём» или «Позвать»; «Изменить» только у автора |
| Новая идея | Ссылка или название. Название и фото берутся из ссылки сразу, остальное собирает скаут. Автор правит любое поле |
| Карточка встречи | Статус, когда, где, «а потом», билеты, отмена |
| Общее время | Сетка окон двоих. Совпало окно: список совпавших идей с «Идём» |
| Помощник | Чат. Нет в данных: «нет», ссылка «посмотреть сейчас», запрос скауту |
| Дела | «Ждёт ответа», «Просрочено», «Сегодня», «Позже», «Сделано за 7 дней» |
| Карточка дела | Кто, срок, повтор, заметка. Кнопки зависят от того, чьё дело |
| Планы | Календарь: встречи и занятость. Дел нет. Панель дня, «Я занят», «Найти общее время» |
| Как прошло | «Понравилось / Не очень / Не ходили», каждый за себя |
| Профиль | История встреч, история дел, «Мой вкус», «Настройки». Открывается с аватаров на главной |
| Настройки | Три группы: для меня, для пары, данные. В строке текущее значение |

## Правила

1. **Одно предложение, один механизм.** Время встречи, перенос, место «а потом», просьба о деле: один предложил, второй отвечает «Да / Нет» в строке. Автор видит «ждём», потом ответ и следующее действие.
2. **Три места, один ответ.** Предложение лежит на главной, в карточке и в боте. Ответил в одном: в остальных гаснет.
3. **Без ответа.** Через сутки адресату напоминание. Через трое суток у автора строка «без ответа»: «Напомнить», «Отозвать».
4. **«Идём» ведёт в карточку встречи этой идеи** из любого места. Партнёр идею не отмечал: кнопка «Позвать», путь тот же.
5. **Ничего не решается за пару.** Встреча в планах после «Да» второго.
6. **Нет тупиков.** У пустого состояния одна кнопка дальше. После действия строка-подтверждение, у обратимых «Вернуть».
7. **Назад по шагам**, подпись «‹ откуда пришёл».
8. **Помощник честный.** Ответ скаута получает тот, кто спрашивал: чат, главная, бот.
9. **Словарь.** Идея, отметка, совпало, встреча, место «а потом», дело, предложение, афиша, скаут, помощник.

## Статусы встречи

без времени → ждём ответа → в планах → прошла (оценки каждого) ; отменена.
Перенос это новое предложение времени: старое действует до «Да». Отмена через лист с последствиями, партнёр получает строку.

## Механика дел

| Состояние | Где лежит | Что дальше |
|---|---|---|
| Открыто | Дела: «Сегодня» или «Позже» | галочка, передать, изменить, удалить |
| Ждёт ответа | у адресата: главная, бот, верх вкладки; у автора: верх вкладки | «Беру» или «Не могу» |
| Вернулось | у автора: главная и верх вкладки | «Беру сам», «Кто угодно» |
| Просрочено | верх вкладки красным, сводка на главной, утреннее сообщение бота | галочка, «Перенести срок» |
| Сделано | низ вкладки, 7 дней, с именем и днём | «Вернуть» |
| В истории | Профиль → История → Дела | только чтение |
| Повтор | после галочки сделанное в «Сделано», в списке следующее с новой датой | |
| Удалено | нигде, 5 секунд «Вернуть» | |

Кнопки карточки: моё: «Сделано», «Передать»; партнёра: «Напомнить», «Забрать себе»; кто угодно: «Беру», «Сделано».
В первую версию не входят: списки покупок, вложения, третьи исполнители, шаги внутри дела.

## Настройки

| Раздел | Чьё | Что | По умолчанию |
|---|---|---|---|
| Уведомления | моё | что дублировать в бот; тихие часы | всё, кроме находок скаута; 23–8 |
| Календарь | моё | встречи в телефон; занятость: сам или из календаря | да; сам |
| Вход и устройства | моё | устройства, выход на остальных | Telegram |
| Встречи | пары | бюджет, город, как добираться между местами | до 5 000 ₽, пешком до 15 мин |
| Скаут и афиша | пары | виды событий, частота, чего не предлагать | кино, концерты, еда; каждый день |
| Дела | пары | время напоминания, срок хранения сделанных, просроченные на главной | 9:00, 7 дней, да |
| Пара | пары | партнёр, выход | |
| Данные | моё | скачать, удалить | |

Выход из пары: общие идеи, встречи и история остаются тому, кто остался; уходящий получает копию своих идей.

## Сервер

Go-сервер остаётся, делится на модули. База только растёт: новые таблицы и колонки.

| Модуль | Отвечает за | Новое в базе |
|---|---|---|
| proposals | предложения, ответы, напоминание и «без ответа» | `proposals(id, space_id, kind, ref_id, author_id, payload, state, created_at, answered_at, reminded_at)` |
| inbox | «Ждёт тебя»: предложения плюс системные строки (скаут ответил, билеты, как прошло, отмена) | `inbox_items(id, space_id, member_id, kind, ref_id, title, state, created_at)` |
| meeting | встреча поверх нынешних раундов: статусы, место «а потом», билеты, оценки | колонки в `rounds` |
| chores | состояния, срок, повтор, история | колонки в таблице дел |
| settings | мои и общие настройки | `member_settings`, `space_settings` |

Маршруты: `GET /api/inbox`, `POST /api/proposals`, `POST /api/proposals/{id}/answer`, `POST /api/proposals/{id}/withdraw`, `GET /api/history`, `GET|PUT /api/settings`. Бот отправляет то же предложение с кнопками и принимает ответ.

## Порядок работ

Новый интерфейс пишется в `web/src/v2` и до последнего шага открывается только по `?v2=1`, чтобы нынешнее приложение работало.

1. Сервер: предложения и «Ждёт тебя», сообщения бота с кнопками, таймауты.
2. Сервер: дела и настройки.
3. Интерфейс: каркас (панель, переходы со стеком, набор деталей) и главная.
4. Идеи, карточка идеи, новая идея по ссылке.
5. Встреча, «а потом», билеты, отмена, «как прошло», Планы, общее время.
6. Дела, профиль, история, настройки.
7. Вход и пара, удаление старых экранов, включение для всех.

Каждый шаг: тесты на новое поведение, e2e по своим сценариям из пятнадцати (вкладка «Сценарии» прототипа), PR по шаблону.
