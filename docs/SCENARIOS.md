# «Вдвоём» — вкладки, экраны и сценарии

Каждый сценарий ниже — отдельный e2e-тест (`e2e/*.spec.ts`, ID в названии теста). Сервер считает всё сам; AI только объясняет и предлагает кнопками.

## Вход

| Экран | Что видно | Доноры |
|---|---|---|
| **Лампа** (каждый холодный старт) | Тёмная комната, торшер сам зажигается за ~0,8 с: свет, луч, светлячки. Шнур можно дёрнуть — свет гаснет/зажигается | lamp_login_animation |
| **Интро частиц** (если уже вошли) | Частицы из луча лампы собираются в знак — два круга, потом в сердце, потом рассыпаются в главный экран. Полная версия раз в день, короткая — в остальные разы, тап пропускает | particleAnimation |
| **Форма входа** (если не вошли, стеклянная карточка в свете лампы) | Три способа: **Telegram** · **Face ID** · **Логин и пароль** | lamp_login_animation, glassy_login_forms |

Способы входа:
- **Внутри Telegram** — автоматически по `initData`. Если в настройках включена «Защита Face ID», при запуске лампа просит биометрию через `Telegram.WebApp.BiometricManager`.
- **В браузере через Telegram** — кнопка открывает бота `t.me/<bot>?start=login_<код>`, бот спрашивает «Войти в браузере?» → «Да, это я», страница сама входит (опрос кода, код живёт 5 минут, срабатывает один раз).
- **Face ID / Touch ID в браузере** — passkey (WebAuthn). Добавляется в «Мы → Безопасность», вход — одной кнопкой.
- **Логин и пароль** — задаются в «Мы → Безопасность» (PBKDF2-SHA256, 600 000 итераций). Пять неверных попыток — пауза на 15 минут.

Сессия в браузере — httpOnly-кука на 30 дней, список сессий и «выйти везде» в настройках.

## Навигация

- **Пилюля-таббар** (5 вкладок): у активной вкладки тёмная пилюля с подписью; переезд на пружине, иконки анимируются при выборе. Справа круглая «+». *(navigation_tabs_v4 / navigation1, svg_animations)*
- **Dynamic Island** сверху на всех вкладках: в свёрнутом виде — живой статус («Ход Насти · шаг 2 из 3», «Сб 19:30 · Ужин · через 2 дня», «3 идеи ждут отметки»). По тапу раскрывается на пружине 380/28: быстрые действия — «Выбрать вместе», «Удиви нас», «Добавить идею», «Спросить помощника» — и строка статуса партнёра. *(navigation_tabs_v4 / navigation3)*

## Вкладки

### 1. Главная
- Dynamic Island.
- Главный блок по состоянию: **нет партнёра** → приглашение; **идёт выбор** → карточка с живой рамкой, шагом, «чей ход»; **встреча запланирована** → билет с обратным отсчётом; **иначе** → «Куда сходим на выходных?» и «Выбрать вместе».
- «Удиви нас» (🎲) и «Что посоветуешь?» → шторка с одной идеей: «Давай!» / «Другую» / «Рандом».
- **Метрики** (стиль dashboard_v7, оранжевая тема): встреч за месяц (столбики), совпадение вкусов (дуга-гейдж), идей в копилке (спарклайн), потрачено ₽ (столбики).
- **График «Наши встречи»** — плавная оранжевая линия с заливкой по месяцам и подсказкой-пиком.
- «Отметь, чего хочется» — лента карточек с кнопками оценки, «Очень» — с анимацией сердца.
- «Скоро» — ближайшая встреча и дела с дедлайном на неделе.

### 2. Копилка — папки
- Сетка **папок** (svg_animations / FolderWidget): «карман» папки в цвете категории, внутри три мини-обложки идей; при наведении или касании они веером выезжают, а второй тап открывает папку.
- Папки: умные — **Хотим оба**, **Понравилось** (сердце), **Скоро закончится**, **Новое**, **Не отмечено**; по категориям — Еда, Культура, Прогулки, Спорт, Другое; плюс **Дела** и **Архив**.
- Поиск по копилке.
- Внутри папки — сетка карточек идей, отметки обоих (оценку партнёра видно только после своей).
- Карточка идеи: обложка, адрес, цена, длительность, срок, заметка, ссылка, «Твоя оценка» (Хочу / Очень ♥ / Пропущу), «Идём сюда — найти время», правка, в архив / вернуть.
- Дела: кто делает (я / партнёр / кто угодно), срок, «Сделано».

### 3. Календарь
- Месяц в стиле dashboard_v7: сегодня — кольцо, запланированные встречи — оранжевые, прошедшие — зелёные, дедлайны дел — точка; листание по месяцам.
- Под календарём — «Запланировано» выбранного дня, а без выбора — ближайшие события. Строки ведут в встречу или идею.
- Тап по свободному будущему дню → «Выбрать вместе на этот день» (выбор, где сетка времени начинается с этого дня).
- Сверху счётчики месяца: встреч, часов вместе, потрачено.

### 4. Помощник
- Шар из частиц в шапке (сфера из particleAnimation): крутится, пока думает, и превращается в сердце, когда предлагает план.
- Чат, подсказки-примеры, карточки идей и встреч в ответах, кнопки-действия (выполняются только нажатием, один раз).
- Лимит — 40 вопросов в день; без AI-ключа работает на правилах.

### 5. Мы
- Карточка пары, гейдж «Совпадение вкусов», счётчики.
- **Где мы были** — встречи с фото и «повторим ♥».
- **Понравилось** — идеи с «повторим», с анимированным сердцем.
- **Настройки**: бот сам предлагает идеи (режим / день / час), день планирования, бюджет, тема (как в Telegram / светлая / тёмная).
- **Безопасность**: защита Face ID (в Telegram), passkey для браузера, логин и пароль, активные сессии, «выйти везде».
- Пригласить партнёра (если один).

## Встреча (сквозной экран выбора)
1. **Время** — сетка 3 дня × утро/день/вечер, можно вести пальцем; свои отметки партнёр не видит.
2. **Ожидание** — две сходящиеся окружности и «Ждём Настю».
3. **Не совпало** — подсказка добавить слоты.
4. **Голосование** — колода из трёх карточек: свайп вправо — голос, влево — следующая, кнопка «Голосую». «Другая тройка», «Ни один». Голос партнёра скрыт до своего.
5. **Разошлись** — оба голоса и компромисс «вы оба не против».
6. **Совпало** — вспышка, билет, «Подтверждаю»; без двух «да» встреча не планируется.
7. **Запланировано** — билет, «В календарь» (.ics), «Перенести», «Отменить»; напоминание за 2 часа.
8. **После** — «Сходили?» → «Да / Перенесли / Не получилось» → «Повторим?» → фото в боте.
9. **Закрыто** — 48 часов без ответа или отмена.

## Бот
`/start`, приглашение, вход в браузер; ссылки и идеи → карточка с оценкой; «Это то же?» при похожей; уведомления партнёру пачкой раз в 3 часа; выбор кнопками; **раз в неделю сам предлагает идею** (по оценке / рандом / через неделю); напоминания; ночью (23–9) молчит; `/surprise`, `/ask`, `/plans`, `/invite`, `/help`.

## Сценарии (e2e)

| ID | Сценарий | Проверяем |
|---|---|---|
| E01 | Знакомство через бота | /start → приглашение → второй входит → оба получили приветствие; повтор ссылки не срабатывает |
| E02 | Один в приложении | Пустое состояние, приглашение, идеи копятся |
| E03 | Вход в браузере через Telegram | Лампа → «Войти через Telegram» → нажатие в боте → вошли; код одноразовый |
| E04 | Логин и пароль | Задать в настройках → выйти → войти; неверный пароль → ошибка; блокировка после 5 попыток |
| E05 | Face ID (passkey) | Виртуальный аутентификатор: добавить → выйти → войти |
| E06 | Интро | Лампа зажглась сама → частицы → главная; тап пропускает |
| E07 | Идеи из бота | Текст, ссылка (разбор og:/ld+json), дубль, похожая → «Это то же», карточка с оценкой |
| E08 | Копилка и папки | Папки открываются, умные папки считаются верно, поиск, правка, архив и возврат |
| E09 | Оценки и приватность | Оценка партнёра скрыта до своей; «Очень» — анимация сердца |
| E10 | Выбор: счастливый путь | Время → голос свайпом и кнопкой → совпало → подтверждения в приложении и в боте → .ics |
| E11 | Голоса разошлись | Компромисс, другая тройка, «Ни один» |
| E12 | Время не совпало | Подсказка и повторная отметка |
| E13 | Другое время и отмена | Перенос сохраняет идею; отмена присылает cancel-.ics |
| E14 | Молчание | Через 12 и 36 часов напоминания, через 48 — выбор закрыт |
| E15 | После встречи | Напоминание за 2 часа, «Сходили?», «Повторим?», фото, история и «Понравилось» |
| E16 | Бот сам предлагает | Среда 13:00 → идея обоим → «Другую» / «Рандом» / «Давай!» → выбор времени |
| E17 | Удиви нас в приложении | Шторка, «Давай!» открывает выбор с готовой идеей |
| E18 | Помощник | Вопросы, карточки, кнопки, одноразовость кнопок, добавление только нажатием |
| E19 | Календарь | Встречи и дедлайны на днях, выбор дня, «Выбрать вместе на этот день» |
| E20 | Настройки | Режим предложений, день, бюджет (дорогие идеи не предлагаются) |
| E21 | Тихие часы | Напоминание на 23:30 приходит в 9:00 |
| E22 | Тема и анимации | Тёмная тема, reduced-motion — интро сокращается |
